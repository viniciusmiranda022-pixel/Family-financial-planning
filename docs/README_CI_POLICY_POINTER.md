# CI e consumo de minutos

A política normativa de uso do GitHub Actions deste repositório está em [`docs/CI_POLICY.md`](CI_POLICY.md).

Para mudanças executáveis, os 12 gates obrigatórios continuam sendo a barreira de merge. A otimização de custo deve ocorrer reduzindo execuções redundantes, nunca reduzindo testes ou cobertura.
